# Changelog

## 1.0.0

First public release for macOS 27 on Apple Silicon.

- Three categories: Always Show, Show on Demand, Always Hidden.
- Native settings with drag-and-drop, category picker, and search.
- Reveal by menu bar click or Option–Command–B, with optional 15-second auto-hide.
- Local saved choices, new-app detection, pause, and recovery on exit.
- Accessibility setup and optional Screen Recording for icon previews.
- Generated app icon, DMG and ZIP downloads, complete source, and GPL-3.0 notices.

Core native behavior was verified on macOS 27.0.1. See [validation](Tests/VALIDATION.md) for limitations.
